## 2. 变更说明（面向用户/开发）

**面向用户**：
- **离线查词**：安装 StarDict 词库（`.ifo`/`.idx`/`.dict`，含 `.dict.dz` 压缩变体）后，阅读中选中单词即可**完全离线**查词，返回词条卡片（词/音标/词性/释义/例句）；多词库按安装顺序取首个命中；未收录词显示"未找到"；未安装词库显示"未安装词库，请先在设置中导入"引导；大小写不敏感（"Apple"≈"apple"，含 Unicode 混合大小写归一）；
- **选句翻译**：选中文本出现"翻译/查词/取消"工具条 → 翻译浮层（loading → 结果 + Provider 名 + "缓存/在线"标记）；失败显示错误文案与"重试"按钮且**不丢原文**；同文+同语言对+同 Provider 二次翻译**命中缓存不联网**（毫秒级返回）；
- **隐私与缓存**：翻译缓存仅存选中文本相关列（无书 ID/路径/设备信息）；设置页提供"清空翻译缓存"一键入口；
- **设置页"词典与翻译"区块**：词库导入/列表/移除、Provider key 输入、清空缓存；
- **在线翻译**：默认 DeepL（需 API key；无 key 时明确提示"未配置 API Key"）；`translate_set_config("echo","")` 可切 Echo 演示（无 key 可体验全链路）；断网/失败给明确可重试错误，不崩溃；
- 既有 EPUB/TXT/MOBI 导入、阅读、进度行为**零变化**（回归验证）。

## 3. 已知问题与限制

1. **在线翻译需 DeepL API key 才能真实调用**：默认 Provider 为 DeepL（Free 层 50 万字符/月，REST POST /v2/translate）；未配置 key 时 `translate` 返回明确的 `NotConfigured`（消息含"API Key"）。**无 key 演示走 Echo**（`translate_set_config("echo","")`，返回"译文:"+原文，全链路可测可演示）——这是设计语义（ADR 关联裁定2），非缺陷；真实 DeepL 往返仅在用户配置 key 后可达（测试不真发网络，`deepl_configured_builds_request_without_network` 只断言错误变体为 Network，网络错误闭包按"无网络 mock 尽力而为降级线"论证，对齐 01-req §5 风险7 / REQ-002 Huff 先例）。
2. **词库需用户导入，发布包不内置大词库**：测试语料（自造 test-tgm/test-tgmx(+.dz)/test-tgz + 坏词库 ×4 + 真实 langdao-ec/ce，来源/sha256 登记于 `core/tests/corpus/README.md` dicts 章节）供 CI/测试使用；**发布包不内置朗道等大词库**（8.7MB+，用户侧从 stardict 词库站自行导入，01-req §4 已明确"线上验证用朗道词库，用户侧安装，不入仓库"）；CI 用例在真实词库文件缺失时跳过（确定性 CI 主语料为自造词库）。
3. **A 片变异未全量评估（环境限制，已如实记录）**：stardict.rs 95 变异体仅评估 40 个（35 caught / 2 missed / 3 unviable），55 个未评估；A 片 2 个 missed 补测已写入源码（`lookup_unicode_mixed_case_normalizes_via_lowercase`，逻辑上可杀）但未复跑验证 → **保守计存活**（若复跑确认则 134/134=100%）。已评估部分 98.5% 达标，未评估部分不影响"已评估口径"结论。
4. **`.dz` 大词库（100MB+）内存策略**：`.dict.dz` 安装期**整文件流式解压落盘**（flate2 GzDecoder → io::copy，无内存峰值，一次性磁盘成本）；查询期对 `.dict` 随机读。100MB+ 词库的 mmap/按区段解压方案留后续 REQ（TRANS-03）记录（01-req §5 风险2 处置，ADR 关联裁定5）。
5. **在线翻译范围**：仅实现 DeepL 真实 Provider + Echo mock（01-req 风险8"一个真实 + mock"）；Google/有道仅留 trait 可插拔位不注册；自动语言检测、词形还原、例句朗读、TRANS-03 进阶管理（词库信息预览/Provider 启用停用/离线优先开关）、TRANS-04 生词本、TRANS-05 对照阅读均**不在本 REQ**（已显式划界）。
6. **分页模式选区**：分页模式仅补"最小 JS 选区回传"（selectionchange 监听 + callHandler），完整选区/上下文菜单/锚定高亮归后续 REQ（REQ-001 演进/笔记 REQ）；真 JS 行为走 FFI/真机验证，widget 测试经 fake PagedViewBuilder 注入选中回调覆盖（03-review §3）。
7. **g 类型（HTML 释义）**：`g` 字段 HTML 原样保留拼接进 definition（UI 侧 `strip_html_tags` 清洗展示）；真实 langdao-ec/ce 实测为 `sametypesequence='m'`（纯文本），g HTML 路径由自造语料 `test-tgmx` 覆盖（降级线对齐 01-req §5 风险8）。
8. **rework-D 遗留**：已闭环无遗留；2 个存活等价豁免（translation.rs:121 仅日志差异、:336 truncate no-op）与 1 个退化死循环转 timeout（L270 `==`→`!=`、L272 `+=`→`*=` 挂起）理由具体（见 04-mutation.md §豁免清单）；无真实业务缺陷需回开发修复。
