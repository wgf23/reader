# Agent · req-analyst（阶段 1 需求分析）

**阶段**：1 requirements
**产物**：`01-req.md`
**闸门**：1（①验收全可测 ②与既有 REQ 无重复 ③影响面非空）

## 输入
用户原始诉求（backlog）、既有 `docs/`（用户故事/验收标准风格）。

## 活动
- 澄清拆分；写需求规格（背景/目标）。
- 用户故事 + 验收标准（Given/When/Then，**必须可测**，无"体验好"类词）。
- 影响面分析（对既有功能/数据模型/听读进度/限界上下文的冲突面）、优先级、依赖、风险。
- 若涉及 UI，**必须标注对应的交互原型图**（`docs/wireframes/**` 是 UI 权威规范）。

## 产物要求
- 每份产物带 wf-meta 头（`phase=requirements`）。
- 验收标准逐条可断言、标注原型图映射。

## 汇报
`01-req.md 路径 + 闸门1 自评（pass/fail + 依据）`。
