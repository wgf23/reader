# 01 · 用户故事与需求规格

> 阅读器设计文档集 · v1.0
> 说明：本期范围 **PC 优先（Windows/macOS/Linux），后续扩展 Android/iOS**；**暂不考虑 Kindle**。明确排除：DRM 破解、KFX。

---

## 1. 角色画像（Personas）

| 角色 | 背景 | 核心诉求 | 影响的功能优先级 |
|---|---|---|---|
| **小林**（重度读者） | 通勤手机 + 晚上电脑读网文/社科，书库大 | 打开快、进度不丢、大量划线批注 | 导入/书架/恢复进度、笔记全套 |
| **陈老师**（外语学习者） | 靠阅读学英语/日语，逐句精读 | 查词、翻译、生词本好用 | 词典/翻译/生词本全套 |
| **老周**（技术书/PDF 用户） | 读技术文档、扫描版 PDF，要整理输出 | PDF 渲染好、笔记能导出 | PDF 管线、导出 |
| **小美**（轻度用户） | 偶尔看看小说 | 简单、好看、不用学 | 默认体验、主题、翻页 |
| **王叔**（通勤听书用户） | 上下班路上/做家务时听小说（参考番茄小说） | 听书好用：音色自然、进度不断、定时关闭 | 听书全套（LISTEN） |

---

## 2. 优先级定义

- **P0**：首版（MVP）必须完成，缺了产品不成立 —— 对应"能导入、能读、能记笔记、能翻译"。
- **P1**：首版应有，可延后 1–2 个迭代；影响体验完整度 —— 含**听书基础**（系统 TTS 朗读 + 听读同进度 + 播放控制）。
- **P2**：后续版本，本期只做接口预留。

## 3. 史诗与用户故事

### Epic A · 图书导入与管理（LIB）

| ID | 故事 | 优先级 |
|---|---|---|
| LIB-01 | 作为读者，我想要把本地书籍文件导入书库，以便统一管理所有书 | P0 |
| LIB-02 | 作为读者，我想要在书架看到封面墙与阅读进度，以便快速找到并继续阅读 | P0 |
| LIB-03 | 作为老周，我想要监控指定文件夹自动入库，以便下载的书自动出现 | P1 |
| LIB-04 | 作为小林，我想要删除书籍，以便清理书库 | P1 |
| LIB-05 | 作为老周，我想要修正元数据（书名/作者/封面），以便书库整洁 | P2 |

**LIB-01 导入**（P0）
- 验收：支持拖拽多文件、选择文件夹、文件选择器三种入口；支持 EPUB/PDF/MOBI/AZW3/TXT/FB2/CBZ；导入在后台执行，界面不阻塞；单个文件失败给出明确原因（如"文件损坏 / 可能受 DRM 保护"）且不影响其他文件；相同内容（按内容指纹 hash）不重复入库。

**LIB-02 书架**（P0）
- 验收：封面墙网格展示封面/书名/作者/阅读进度；点击任意封面 1s 内进入阅读并恢复上次位置；支持排序（最近阅读/书名/作者/添加时间）与筛选（格式/是否读完）；空书库有引导页（"拖入书籍开始阅读"）。

**LIB-03 文件夹监控**（P1）
- 验收：可配置一个或多个监控目录；新增/修改文件自动入库并出现于书架；可暂停/恢复；监控失败静默重试。

**LIB-04 删除书籍**（P1）
- 验收：删除需二次确认；提供"同时删除该书的笔记"选项（默认保留笔记数据）。

### Epic B · 阅读体验（READ）

| ID | 故事 | 优先级 |
|---|---|---|
| READ-01 | 作为所有用户，我想要打开书就接着上次的位置，以便连续阅读 | P0 |
| READ-02 | 作为所有用户，我想要流畅翻页，以便长时间阅读不疲劳 | P0 |
| READ-03 | 作为小林，我想要目录跳转，以便在长书里导航 | P0 |
| READ-04 | 作为小美，我想要调整字号/行距/字体/边距，以便读得舒服 | P0 |
| READ-05 | 作为所有用户，我想要浅色/深色/护眼主题，以便夜间阅读 | P0 |
| READ-06 | 作为老周，我想要全文搜索，以便在书里快速定位内容 | P1 |
| READ-07 | 作为小林，我想要进度条拖动跳转，以便快速翻到任意位置 | P1 |
| READ-08 | 作为小林，我想要阅读统计，以便了解阅读习惯 | P2 |

**READ-01 打开并恢复进度**（P0）
- 验收：点击封面到正文可见：10MB EPUB 桌面 < 500ms，移动 < 1.5s；自动恢复到上次章节与页（含 PDF 页码）；首次打开显示第一章第一页；打开大文件不白屏（先出骨架/进度）。

**READ-02 翻页**（P0）
- 验收：点击左右热区、左右方向键、触控滑动均可翻页；提供**分页模式**与**滚动模式**两种，可切换；翻页动画可设（无/淡入/滑动）；翻页稳定 60fps，无闪烁；翻页后笔记锚定不漂移（见 NOTE-01）。

**READ-03 目录**（P0）
- 验收：侧栏目录树展示全书章节层级（EPUB 的 toc/NCX，MOBI/AZW3 转换后重建）；当前章节高亮并自动展开；点击跳转；目录可收起。

**READ-04 排版设置**（P0）
- 验收：字号 12–32 级可调；行距、对齐（左对齐/两端对齐）、页边距可调；内置 ≥3 种字体（含衬线/无衬线），P1 支持导入自定义字体；调整即时生效且阅读位置不丢。

**READ-05 主题**（P0）
- 验收：浅色/深色/护眼（米黄）三主题；深色下 PDF 反色渲染（白底转黑底）；主题选择全局记忆。

**READ-06 全文搜索**（P1）
- 验收：支持全书搜索，P1.5 支持跨书搜索；结果 < 100ms 返回（FTS5）；结果列表展示上下文片段与章节名；点击定位到书中位置并高亮关键词；支持继续搜索当前章节内。

**READ-07 进度条**（P1）
- 验收：底部进度条显示百分比；拖动时预览章节标题；松手跳转；跳转后支持"返回原位置"。

**READ-08 阅读统计**（P2）
- 验收：按日统计阅读时长、完成书目、连续阅读天数；仅本地数据，不采集上传。

### Epic C · 笔记（NOTE）—— 第一优先级功能

| ID | 故事 | 优先级 |
|---|---|---|
| NOTE-01 | 作为小林，我想要选中文字高亮（多色），以便标记重点 | P0 |
| NOTE-02 | 作为小林，我想要划线，以便区分高亮与强调 | P0 |
| NOTE-03 | 作为老周，我想要给选中文字写批注，以便记录想法 | P0 |
| NOTE-04 | 作为陈老师，我想要一个笔记面板浏览全书笔记并跳回原文，以便复习 | P0 |
| NOTE-05 | 作为小林，我想要编辑/删除/改色笔记，以便整理 | P0 |
| NOTE-06 | 作为所有用户，我想要书签当前页，以便随时回来 | P1 |
| NOTE-07 | 作为老周，我想要把笔记导出为 Markdown/JSON，以便同步到其他工具 | P1 |
| NOTE-08 | （接口预留）笔记未来支持跨设备同步 | P2 |

**NOTE-01 高亮**（P0）
- 验收：选中文本弹出浮动工具条（见线框 06）；高亮支持 ≥4 色；**换字号/换主题/重新分页后高亮不丢失**（文本锚点重定位）；同一段可叠加不同色高亮与批注。

**NOTE-02 划线**（P0）
- 验收：与高亮同一工具条入口，单线样式；其余行为同高亮。

**NOTE-03 批注**（P0）
- 验收：工具条"批注"弹出输入框；批注与锚点一起持久化；可对已有高亮追加批注；批注支持编辑与删除。

**NOTE-04 笔记面板**（P0）
- 验收：面板按章节分组列出全书笔记（色标 + 原文片段 + 批注 + 时间）；面板内可搜索笔记；点击条目跳回原文并临时高亮该位置；面板可悬浮/固定/关闭，桌面端支持快捷键。

**NOTE-05 笔记整理**（P0）
- 验收：任意笔记可删除、改色、编辑；面板内支持多选批量删除；删除前二次确认；删除后锚点数据一并清理。

**NOTE-06 书签**（P1）
- 验收：阅读中一键书签当前页；书签列表独立展示，点击跳转；可与笔记面板并列或并入。

**NOTE-07 导出**（P1）
- 验收：支持 Markdown 与 JSON 两种格式；导出内容含书名/章节/锚点/原文片段/批注/时间；桌面端弹保存对话框；导出过程不阻塞；空笔记给出提示。

### Epic D · 翻译与词典（TRANS）—— 第一优先级功能

| ID | 故事 | 优先级 |
|---|---|---|
| TRANS-01 | 作为陈老师，我想要长按/双击查词（离线词典），以便不打断阅读 | P0 |
| TRANS-02 | 作为陈老师，我想要选中句子/段落翻译，以便理解原文 | P0 |
| TRANS-03 | 作为陈老师，我想要管理翻译 Provider 与离线词库，以便按需选择 | P1 |
| TRANS-04 | 作为陈老师，我想要生词本，以便集中复习生词 | P1 |
| TRANS-05 | 作为陈老师，我想要原文/译文对照阅读，以便精读 | P2 |

**TRANS-01 长按查词**（P0）
- 验收：长按（触控）/双击或快捷键（桌面）选中单词弹出词典卡片：音标/词性/释义/例句；**完全离线可用**（StarDict 词库，无网不降级）；可安装/移除词库（设置页）；查词不打断阅读上下文（浮层定位在词旁）。

**TRANS-02 选句翻译**（P0）
- 验收：选中文本 → 工具条"翻译"→ 弹出译文卡片（见线框 08）；默认翻译整句（跨行自动合并）；Provider 可配（DeepL/Google/有道，默认 DeepL）；**结果按（原文, 源语言, 目标语言, Provider）缓存**，重复查询命中缓存不再调用网络；翻译失败给出可重试提示，不丢原文。

**TRANS-03 Provider 与词库管理**（P1）
- 验收：设置页可启用/停用在线 Provider、填写 API Key、选择默认 Provider；可导入/删除 StarDict 词库并预览词库信息；支持"离线优先"策略（命中词库则不发在线请求）。

**TRANS-04 生词本**（P1）
- 验收：查词卡片一键"加入生词本"；生词本列表（词/释义/添加时间/来源书）可搜索、删除、导出 CSV；生词本内点击词可重新查词。

**TRANS-05 对照阅读**（P2）
- 验收：整本书左右分栏（原文 | 机器译文）对照阅读；译文仅在线生成并按章节缓存。

### Epic E · 设置与平台（SET）

| ID | 故事 | 优先级 |
|---|---|---|
| SET-01 | 作为小美，我想要全局默认设置，以便新书直接按我的习惯打开 | P1 |
| SET-02 | 作为老周，我想要桌面快捷键，以便高效操作 | P1 |
| SET-03 | 作为老周，我想要备份/恢复笔记与设置，以便换机迁移 | P2 |
| SET-04 | 作为所有用户，我想要崩溃不丢数据，以便安心使用 | P1 |

**SET-01 全局默认设置**（P1）
- 验收：默认字号/字体/主题/翻页动画/边距可在设置页配置；新书打开默认套用；单书可临时覆盖（会话内）。

**SET-02 快捷键**（P1）
- 验收：默认快捷键：翻页（←/→ 或 PageUp/Down）、目录（T）、搜索（Ctrl+F）、笔记面板（N）、翻译（Ctrl+T）、高亮（Ctrl+H）；全部可自定义；快捷键面板展示与编辑。

**SET-03 备份恢复**（P2）
- 验收：一键导出笔记+设置+阅读进度为 JSON 文件；支持导入恢复；恢复时按书 ID 映射，缺失的书标记"书未导入"。

**SET-04 数据安全**（P1）
- 验收：笔记/进度采用 SQLite WAL + 原子写入，崩溃不丢已保存笔记；日志可导出用于排障；隐私承诺：除用户主动配置的在线翻译服务外，无任何数据上传。

### Epic F · 听书（LISTEN）—— 番茄小说式听书

> 参考 [番茄小说听书](https://fanqiepc.ijinshan.com/pages/guides/audiobook/index.html) 的功能形态：AI 朗读、多音色、语速调节、定时关闭、后台播放、章节连播、听读进度一体。

| ID | 故事 | 优先级 |
|---|---|---|
| LISTEN-01 | 作为王叔，我想要在阅读页一键切换到听书、从当前位置开始朗读，以便通勤时"听"书 | P1 |
| LISTEN-02 | 作为王叔，我想要听书与阅读共用同一进度，以便听读到哪读到哪、无缝切换 | P1 |
| LISTEN-03 | 作为王叔，我想要章节自动连播，以便长时间听不中断 | P1 |
| LISTEN-04 | 作为王叔，我想要完整播放控制（暂停/跳句/跳章/拖动/快捷键），以便精细控制 | P1 |
| LISTEN-05 | 作为王叔，我想要调节语速与切换音色，以便找到听得最舒服的配置 | P1 |
| LISTEN-06 | 作为王叔，我想要定时关闭（睡眠定时），以便睡前听书不耗电 | P1 |
| LISTEN-07 | 作为王叔，我想要切到后台继续播放并可用系统媒体键控制，以便边做事边听 | P1（桌面）/ P2（移动通知栏） |
| LISTEN-08 | 作为王叔，我想要朗读时当前句在正文中高亮（跟读），并支持点击任意句开读 | P1 |
| LISTEN-09 | 作为王叔，我想要完全离线的朗读（系统 TTS），以便没网也能听 | P1 |
| LISTEN-10 | 作为王叔，我想要 AI 在线音色与本地神经音色可选，以便音色更自然（番茄同款路线） | P2 |
| LISTEN-11 | （评估项）声音克隆：用户录音生成个人音色（番茄同款） | P2 评估 |

**LISTEN-01 一键听书**（P1）
- 验收：阅读页工具条提供"听书"入口（见线框 09）；点击后从**当前阅读位置**开始朗读；进入听书不改变阅读位置；退出回到阅读页，位置一致。

**LISTEN-02 听读进度统一**（P1）
- 验收：朗读进度与阅读进度为**同一个 Locator**（复用 `reading_progress`，无需新表）；听书时进度条拖动 = 移动阅读进度；退出听书回到阅读位置无缝衔接；关闭应用后重开，可从上次听读位置继续。

**LISTEN-03 章节连播**（P1）
- 验收：章末自动播下一章（按目录顺序）；最后一章播完停止；可在听书设置中关闭连播。

**LISTEN-04 播放控制**（P1）
- 验收：播放/暂停、上一句/下一句、上一章/下一章、句级进度拖动均可用；桌面快捷键：空格暂停/继续、←/→ 跳句、Ctrl+→ 跳章；控制响应 < 100ms。

**LISTEN-05 语速与音色**（P1）
- 验收：语速 0.5–3.0x 实时可调（调节即刻生效）；默认 ≥2 种音色（系统男/女声），P2 提供 AI 音色（见线框 10）；音色/语速选择全局记忆。

**LISTEN-06 定时关闭**（P1）
- 验收：提供 15/30/45/60 分钟、本章结束、当前句结束、关闭等选项；定时到自动停止并轻提示；定时期间可随时取消。

**LISTEN-07 后台播放**（P1 桌面 / P2 移动）
- 验收（桌面）：最小化/切后台继续播放；系统媒体键（播放/暂停/下一首）与任务栏媒体控件可控制；应用内**迷你播放条**跨页面常驻（不打断其他操作）。
- 验收（移动端，P2）：切后台/锁屏继续播放；通知栏与锁屏媒体控制；来电/其他音频中断后恢复策略正确。

**LISTEN-08 跟读与点读**（P1）
- 验收：朗读时当前句在正文中高亮（见线框 09）；点击正文任意句，从该句开始朗读；高亮随字号/语速调整保持一致。

**LISTEN-09 离线朗读**（P1）
- 验收：默认系统 TTS，完全离线可用；中文/英文使用系统可用语音；系统缺中文语音时给出安装提示并引导本地神经音色（P2）。

**LISTEN-10 AI 音色增强**（P2）
- 验收：在线 AI 音色（火山/Azure 等 Provider）与本地神经音色（Piper）可选安装；音色包按需下载到用户数据目录（**不增加安装包体积**）；下载中断可续传；在线音色需显式授权（将发送正文文本，见隐私条款）。

**LISTEN-11 声音克隆**（P2 评估）
- 验收（评估通过后）：按引导录制 10–30s 语音生成个人音色；克隆音色仅本地使用；提供合规声明与一键删除入口。

## 4. 非功能需求（汇总）

| 类别 | 要求 |
|---|---|
| 性能 | 见技术文档 §6 性能预算；打开/翻页/搜索均有硬性指标 |
| 体积 | 桌面安装包 < 40MB；移动端每 ABI < 25MB |
