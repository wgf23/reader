## 核心决策速览

- **技术栈**：Flutter（UI，一套代码六平台）+ Rust（核心，flutter_rust_bridge 桥接）+ 系统 WebView 分页排版（reflow）+ PDFium（PDF）+ SQLite/WAL（存储）+ StarDict（离线词典）+ Provider 式在线翻译 + 听书（flutter_tts / just_audio / audio_service）。
- **格式策略**：EPUB 原生；MOBI/AZW3/TXT/FB2 统一转换为"规范 EPUB"后走同一条排版管线；PDF/CBZ 走独立固定页管线。不做 KFX、不做 DRM 破解。
- **功能重心**：笔记（高亮/划线/批注，文本锚定重排不失效）与翻译（离线查词 + 在线选句翻译 + 缓存）为 P0；**听书**（[番茄小说式](https://fanqiepc.ijinshan.com/pages/guides/audiobook/index.html)：系统 TTS 离线朗读、听读同进度、定时关闭、后台播放）为 P1。
- **体积/性能**：桌面包 < 40MB；10MB EPUB 打开 < 500ms；翻页 60fps；搜索 < 100ms。

## 后续建议

设计评审通过后，按 P0 里程碑开始实现：
**P0（骨架）**：Flutter 壳 + Rust 核心桥接 + EPUB/TXT 解析渲染 + 翻页/目录/主题 → **P1（核心体验）**：PDF、MOBI/AZW3、笔记全套、翻译词典全套、**听书基础**（系统 TTS + 听读同进度 + 控制/定时/后台播放）→ **P2**：搜索、导出、同步接口、听书增强（AI 音色 / Piper）→ **P3**：Android/iOS（含移动端后台播放与锁屏控制）。
