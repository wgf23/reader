# 阅读器页交互重构 —— 原型设计（参考 Kindle）

> 范围：阅读器页（核心痛点）+ 书架页微调。目标：**沉浸阅读 + 极简工具 Chrome**，
> 参考 [Kindle 交互](https://www.manualzz.com/doc/22670132/#show#2)：点击屏幕中央呼出工具栏、
> Aa 显示设置、边缘翻页、长按选词。
>
> 状态：**原型待确认** —— 确认后按此实现（工作流 REQ-004）。

## 一、为什么重构

当前阅读器页的三个问题：
1. **右上角按钮混乱**：把"分页/滚动切换、字号、目录"三个功能直接塞在 AppBar 的 `actions` 里，
   用户无法判断是干嘛的；
2. **无沉浸态**：常驻 AppBar 中断阅读，且与"分页/滚动"两模式混在一起；
3. **功能入口离手太远**：翻页只靠底部两个按钮，进度无拖动，目录/字号/主题散落多处。

## 二、参考 Kindle 的交互模型

| Kindle 交互 | 我们的映射 |
|---|---|
| 点击屏幕中央 → 呼出/隐藏工具栏 | 同：点击正文中部 1/3 区域切换 UI 可见性 |
| 沉浸阅读（无 chrome） | 正文全屏，边缘热区翻页 |
| 左右边缘点击/滑动翻页 | 同：左 15% / 右 15% 热区点击翻页（分页模式） |
| Aa 显示设置（字体/字号/主题） | 底部"Aa"按钮 → 弹出显示设置面板 |
| 底部工具栏：进度条/目录/书签/翻页 | 同 |
| 长按选词 → 词典/翻译/笔记 | 同（浮动工具条） |
| 位置/百分比显示 | 进度条右侧显示百分比 |

## 三、新交互逻辑（阅读器页）

### 3.1 全局（两模式统一）
```
沉浸阅读态（默认，无任何 chrome）
   ├─ 点击正文中部 1/3 区域 → 呼出 顶栏 + 底栏（淡入）
   ├─ 点击左边缘 15% → 上一页；右边缘 15% → 下一页（分页模式）
   ├─ 上/下滑动 → 翻页（分页模式连续翻页 / 滚动模式滚动）
   ├─ 长按/选中文本 → 浮动工具条（划重点/笔记/翻译/查词/复制）
   └─ 呼出后：点击中部再点 → 隐藏工具栏（回到沉浸）
```

### 3.2 顶栏（呼出时，顶部浮层）
| 位置 | 控件 | 动作 |
|---|---|---|
| 左 | ← 返回 | 回书架 |
| 中 | 书名 · 章节名 | — |
| 右 | ⋯ 更多 | 菜单：阅读统计 / 听书 / 笔记 / 导出 |

### 3.3 底栏（呼出时，底部浮层）
```
[ 上一章 ] [ ☰ 目录 ] [ ────── 进度条(可拖) ────── 42% ] [ 书签 ] [ Aa ] [ 下一章 ]
```
| 控件 | 动作 |
|---|---|
| 上一章 / 下一章 | 章切换（边缘翻页到章末自动续章） |
| ☰ 目录 | 侧拉目录抽屉（章节列表 + 当前章高亮） |
| 进度条 | Slider：拖动实时预览章节，松手跳转；右侧显示百分比 |
| 书签 | 当前页加/取消书签（书签图标状态） |
| **Aa** | 弹出**显示设置面板** |

### 3.4 Aa 显示设置面板（底部弹层）
```
┌──────────────────────────────────────────┐
│ 字号   ──○──────────────────── (18pt)      │
│ 字体   [ 系统默认 ▾ ]  [ 衬线 ] [ 无衬线 ]   │
│ 主题   [ 浅色 ] [ 深色 ] [ 护眼 ]           │
│ 行距   [ 紧凑 ] [ 标准 ] [ 宽松 ]           │
│ 翻页   分页模式 ● / 滚动模式 ○              │   ← 模式切换移到这里（不再是右上角按钮）
└──────────────────────────────────────────┘
```
> 模式切换（分页/滚动）从 AppBar 移除，改到这里 —— 解决"右上角看不懂"的根本。

### 3.5 长按选词浮动工具条（选中文本上方）
```
[ 划重点 ] [ 笔记 ] [ 翻译 ] [ 查词 ] [ 复制 ]
```
（与 REQ-003 已实现的翻译/查词打通）

## 四、与现状的差异（改动清单）

| 现状 | 新设计 |
|---|---|
| 常驻 AppBar（返回/书名/三个功能按钮） | 沉浸态无 AppBar；点击中央呼出顶栏+底栏 |
| 右上角：模式切换/字号/目录 三按钮 | 全部移除；模式切换与字号 → Aa 面板；目录 → 底栏 ☰ |
| 底部：仅两个章导航按钮 | 底栏含上一章/目录/可拖进度条/书签/Aa/下一章 |
| 无书签 | 底栏书签 |
| 进度无拖动 | 进度条 Slider 可拖 |
