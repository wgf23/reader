## 评审要点（建议对照检查）

1. **阅读器主界面**：翻页热区大小是否合理（误触）、进度条是否直观；
2. **选择工具条**：6 个操作是否足够/过多；工具条遮挡问题（应随选中区浮动、可拖离）；
3. **笔记面板**：章节分组 vs 时间分组哪个更好用？导出入口是否够明显；
4. **翻译浮层**：查词卡片与翻译卡片是否该合并为同一浮层体系（交互一致性）；
5. **书架**：是否需要"列表视图"切换（大书库场景）；
6. **导入**：文件夹监控入口（LIB-03）应放在导入页还是设置页；
7. **听书模式（09）**：跟读高亮是否只在"听书模式"下显示；控制条是否需常驻可折叠；"点击正文任意句开读"（点读）的命中区域；
8. **听书设置（10）**：音色/语速/定时是否应放全局设置还是听书浮层内（番茄小说放在听书面板里）；在线 AI 音色的授权提示是否足够显眼。

> 线框为低保真，最终视觉/间距/图标以实现阶段高保真为准。
